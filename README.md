# VibeFarsi Shop Admin

Persian RTL shop dashboard built with [VibeFarsi](https://vibefarsi.ir) components (Paper theme).

**Stack:** Next.js 16 · React 19 · Tailwind CSS v4 · Vazirmatn

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

| Route | Screen |
| --- | --- |
| `/` | Overview |
| `/orders` | Orders |
| `/products` | Products |
| `/customers` | Customers |
| `/wallet` | Wallet |
| `/invoices` | Invoices |
| `/booking` | Booking |
| `/support` | Support |
| `/notifications` | Notifications |
| `/help` | Help |
| `/settings` | Settings |
| `/login` | Auth |

## Notes

- Default theme is light; toggle + GitHub link live in the sidebar header.
- Copy is Persian; layout is RTL (`dir="rtl"`).
- UI is copy-paste from VibeFarsi (MCP / registry), not an npm kit.
